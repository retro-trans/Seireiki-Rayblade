# Seireiki Rayblade English v0.7.51

This release fixes the reported album and battle UI defects while retaining the Native 1x font and earlier New Game/mission-dialogue runtime repairs.

**Known hardware issue: long-range attacks can show a black scene with no animation, for both player and CPU units. This is not fixed in 0.7.51. The project owner reports that Flycast does not exhibit this issue.**

## Changes

- Restore missing Memory Album captions using texture sizes accepted by the game's native loader. Translate the album heading to **Memory Album**. Original photos and caption positions are preserved; the new caption pages use 458,752 fewer bytes of graphics memory.
- Improve the small **Trust Gauge** and character-name tabs using the original Skies font artwork at a consistent scale.
- Fit sorting labels inside their frame: **By HP**, **By Prana**, **By LV**, and **By EXP**.
- Move weapon **P/W** markers out of the Power values. The shared name-measurement and hardware compatibility routines are unchanged.

The game files are the same as the local 0.7.51 UI test build. Publication changes patch metadata and packaging, not game behavior. No HD font mode or emulator texture replacement is included.

The ZIP bundles contain the same DCP files plus instructions and notices. This release does not use xdelta. Older published assets remain available unchanged.

## Validation and remaining issues

Native checks cover texture acceptance, caption registration and UVs, weapon-marker callers, sorting layouts, archive lookups and compressed-resource round trips. Both public DCP routes are applied to their actual inputs and checked against the same 140 game files, boot metadata and original CD audio. Automatic metadata and source recognition are checked separately.

These checks do not establish a full hardware gameplay pass. Physical hardware visual confirmation of the four UI fixes remains pending. The ranged-attack animation issue above remains open; emulator success is not proof of a hardware fix.

The translation is unfinished: 503 held/untranslated story rows, an unidentified room tag, the long Chapter 6 save-label overlap, independent proofreading and full-route/extended-session testing remain. [Stage 9 CG issue #5](https://github.com/retro-trans/Seireiki-Rayblade/issues/5) is also unresolved.
