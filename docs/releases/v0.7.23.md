English translation **work in progress** for **Seireiki Rayblade**, Dreamcast Japanese edition **T-42201M**.

**v0.7.23** repairs the reported Stage 6 text corruption, battle coordinates, split-screen clipping and selection bars. It removes HD mode and uses only the original Skies **1× font**. True **640×480** rendering, VGA support and original Japanese opening/demo movies are retained.

### Install or upgrade

Use [Retro Trans Tools](https://github.com/retro-trans/retro-trans-tools) **0.4.1 or later**. Refresh the catalog, choose **Automatic**, select your complete disc folder, and choose **0.7.23**. The catalog supports both:

- **Original Japanese BIN/CUE → 0.7.23:** use the full `Rayblade-English-v0.7.23-xdelta.zip` package for manual patching.
- **Last public release 0.7.11 → 0.7.23:** use `Rayblade-English-v0.7.11-to-v0.7.23-upgrade.zip` for manual patching. This upgrade is for the exact public 0.7.11 output, rather than an intervening local test build.

Retro Trans verifies the inputs and writes all five tracks plus `Seireiki Rayblade English v0.7.23.gdi` into a new folder. Keep the source files and checksum verification enabled. Fresh-boot the new GDI and load a normal VMU save; emulator save states can retain older code and graphics.

The packages include manual instructions and source/target hashes. Match the patch route to your input. All three deltas in that route are supplied, including the descriptor; Tracks 1, 2 and 4 are copied unchanged. Automatic recognizes unchanged components and can skip identity operations. An unpacked five-track dump is required; automatic GD-ROM CHD extraction/recompression is outside this release contract.

### Changes since 0.7.11

- **Stage 6 text corruption ([issue #1](https://github.com/retro-trans/Seireiki-Rayblade/issues/1)).** Generated text now uses exact, lossless texture compression when its pixels can be represented. This reduces video-memory use without changing glyphs, colors, alpha or wording. The supplied save passes both previously broken bridge exchanges, the reported battle menus, and a normal battle save followed by a separate cold-boot reload in Flycast.
- **1× font only and texture-memory repairs.** Removed the HD font bank and title-screen font selector. Repaired white UI panels, map labels and portrait swaps, and restored the original geometry-memory reservation to recover texture capacity.
- **Battle coordinates.** Movement grids, selection arrows, targeting reticles and animation primitives now receive the correct display-coordinate conversion. Gameplay range, target selection and unit statistics are unchanged.
- **Split-screen combat.** Corrected inclusive clipping bounds and remaining line primitives. Removed the misplaced partial divider and blank strip in the reported split battle.
- **Selection bars.** Extended the green bars to cover the text in forecast, counter-policy and action menus, including Counterattack, Select Weapon and Abilities.
- **Startup and movies.** Corrected loading-screen placement and startup graphics handling, and removed the flashing bottom movie edge. Original opening/demo video and audio remain unchanged.

### Verification and limits

Both the full original-input route and the **0.7.11 upgrade** pass complete-disc application through the actual Retro Trans Automatic backend. Both produce the same five tracks and GDI. All fifteen modified payloads re-extract exactly, changed-sector EDC/ECC passes, and the full unrelated-track comparison passes. All 4,041 original movie/audio sectors are preserved. Native execution checks and fresh normal-VMU gameplay confirm the targeted Stage 6, battle and selection-bar repairs. Detailed evidence is included in `GAME-VALIDATION-v0.7.23.json` and the tagged repository's research records.

This remains an **unfinished machine translation**, without complete independent Japanese-to-English proofreading. There are **503 held/untranslated story rows**, unsupported original text can show fallback marks, and one room tag remains unidentified. The existing long Chapter 6 save label can overlap its “In Battle” label. Physical Dreamcast VGA/TV compatibility, complete routes and extended sessions remain unverified.
