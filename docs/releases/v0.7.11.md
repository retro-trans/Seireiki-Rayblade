English translation **work in progress** for **Seireiki Rayblade**, Dreamcast Japanese edition **T-42201M**.

**v0.7.11** brings the Native/HD font selector, true 640×480 rendering, corrected original-movie sizing and the accumulated map, menu, numeric and room-name fixes from local builds 0.7.3–0.7.11. Location banners now fit the lettering like the Japanese version. VGA support and the original Japanese opening/demo movie content are retained.

### Apply

**The easiest way:** [Retro Trans](https://github.com/retro-trans/retro-trans-tools) **0.4.1 or later** can apply the complete verified multi-file solution. Refresh its catalog, choose **Automatic**, select your original BIN/CUE folder or `Seireiki Rayblade (Japan).cue`, choose v0.7.11 and click **Patch**. It verifies the inputs and produces five BIN tracks plus the English GDI in a new folder.

Use the unpacked five-track Japanese dump matching `SOURCE-HASHES-v0.7.11.txt`. GD-ROM/multi-track CHD conversion is not supported by this release contract. Apply to your original Japanese disc set; Earlier English releases and local test images are not valid inputs for these full patches.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) or [xdelta3](https://github.com/jmacd/xdelta) accepts the same deltas. Create a new folder and apply all three:

| Your original input | Patch |
|---|---|
| Track 3 | `Rayblade-English-v0.7.11-Track03.xdelta` |
| Track 5 | `Rayblade-English-v0.7.11-Track05.xdelta` |
| `Seireiki Rayblade (Japan).cue` | `Rayblade-English-v0.7.11-GDI.xdelta` |

Keep the patched track filenames unchanged. Copy original Tracks **1, 2 and 4** into the new folder and save the descriptor output as **`Seireiki Rayblade English v0.7.11.gdi`**. The complete folder contains all five tracks and that GDI. Open the GDI in Flycast.

See the [README](https://github.com/retro-trans/Seireiki-Rayblade#apply) and `README-v0.7.11.txt` for commands. Keep source checksum verification enabled. These are full patches from the original Japanese inputs, not upgrade patches from a previous English build.

### Changes since v0.7.2

* **Native and HD font choices.** Native is the cold-boot default. At the title screen, **X selects Native**, and **Y selects HD**. The choice lasts until reset and is not written to the VMU. Native uses original Skies Latin glyph pixels at the game's true **640×480** output; the main source cell is **12×24**, and the compact cell is **8×16**. Every font texture remains at or below 1024 pixels per dimension. No emulator texture pack is required.
* **Original movies at the correct size.** Opening/demo video and audio remain byte-for-byte original Japanese content, without added English overlays. Corrected the application drawing size/position so the 320×192 movie fills a 640×384 area centered vertically in the 640×480 output.
* **Story choices and map labels.** Restored separate selectable options where general dialogue reflow had joined them. Improved all ten world-map labels with native-scale lettering, a thin outline and stable pixel positioning.
* **Names, menus and markers.** Shortened thirteen weapon display names and seven matching event-movie titles to fit their columns. Aligned Trust/Skills headings with their square markers. Reworded all eleven Trust help entries to state their complete effects and added compact popup aliases with room for their numeric values.
* **Correct SP signs and fitted notices.** Signed fields now show Latin +/− signs instead of missing-glyph question marks; neutral displays **+0**, with the actual values unchanged. The full-VMU warning fits three lines and still requires at least eight free blocks. The overflowing Register Topic title is now **Topic Log**.
* **English room tags.** Translated 33 room-selection name tags, including Clovis and Arthur, using uniformly scaled original Skies glyphs. One unidentified tag remains unchanged.
* **Fitted location banners.** Headers now use actual variable font widths while retaining the original right alignment, padding, border artwork and animation. The reported Summoning Facility title reserves 138 logical pixels instead of 232.
* **Previous features retained.** VGA support, original opening/demo content, English gameplay drafts, dialogue wrapping and library/battle/UI work remain included.

### Testing and known limitations

The release uses the exact verified local **0.7.11** game output. All fifteen modified payloads re-extract exactly; changed-sector EDC/ECC and the full 1,188,856,032-byte track preservation comparison pass. All three xdelta patches pass decode/full-target SHA-256 round trips. The actual Retro Trans Automatic backend reconstructs all five tracks and the GDI exactly and recognizes the result as 0.7.11.

The latest header fix passes 512 native width checks, 512 native header-placement phases and 2,984 unchanged other-row measurements. Earlier component records include 2,040 signed-number generation/parser cases, Native/HD Trust help/layout checks, original texture decoding and preservation checks. Offline native execution and hash checks do not establish final GPU appearance or complete gameplay compatibility.

**Known issue:** [Stage 6 text corruption, issue #1](https://github.com/retro-trans/Seireiki-Rayblade/issues/1), remains unresolved. Do not treat this release as its fix. Final location-banner appearance, physical Dreamcast VGA/TV compatibility, complete routes and long sessions still need testing. One room tag is unidentified. There are **503 held/untranslated story rows**, and unsupported original text can display fallback marks with the Latin-only font. This remains an unfinished machine translation without complete independent Japanese-to-English proofreading.

Fresh-boot the new GDI and load an ordinary in-game memory-card save. Emulator save states may retain old code or artwork. In Flycast, select **VGA** for its emulated cable when testing VGA output. Native is recommended for original Dreamcast and Flycast 1× output; the title-screen selector also provides HD.

### How it was translated

This is a **machine translation**, produced with large language models and then edited. Codex/OpenAI assisted the drafts, tooling and reverse engineering under the project lead's direction. It has not had complete independent human Japanese-to-English proofreading. Names and terminology are tracked in the glossary. The new room labels and corrected UI descriptions are included; the main story draft coverage is unchanged.
