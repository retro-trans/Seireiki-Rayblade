English translation **work in progress** for **Seireiki Rayblade**, Dreamcast Japanese edition **T-42201M**.

**v0.7.2** adds integrated **VGA support** and restores the **original Japanese opening/demo movies**, removing the added English movie text. It retains the English gameplay drafts, Skies font, dialogue wrapping and menu/map improvements from v0.7.0. Local 0.7.1 was the VGA test build; this release includes that work plus the movie restoration.

### Apply

**The easiest way:** [Retro Trans](https://github.com/retro-trans/retro-trans-tools) **0.4.1 or later** can apply the complete verified multi-file solution. Refresh its catalog, choose **Automatic**, select your original BIN/CUE folder or `Seireiki Rayblade (Japan).cue`, choose v0.7.2 and click **Patch**. It verifies the inputs and produces five BIN tracks plus the English GDI in a new folder.

Use the unpacked five-track Japanese dump matching `SOURCE-HASHES-v0.7.2.txt`. GD-ROM/multi-track CHD conversion is not supported by this release contract. Apply to your original Japanese disc set; English v0.7.0 and local test images are not valid inputs for these full patches.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) or [xdelta3](https://github.com/jmacd/xdelta) accepts the same deltas. Create a new folder and apply all three:

| Your original input | Patch |
|---|---|
| Track 3 | `Rayblade-English-v0.7.2-Track03.xdelta` |
| Track 5 | `Rayblade-English-v0.7.2-Track05.xdelta` |
| `Seireiki Rayblade (Japan).cue` | `Rayblade-English-v0.7.2-GDI.xdelta` |

Keep the patched track filenames unchanged. Copy original Tracks **1, 2 and 4** into the new folder and save the descriptor output as **`Seireiki Rayblade English v0.7.2.gdi`**. The complete folder contains all five tracks and that GDI. Open the GDI in Flycast.

See the [README](https://github.com/retro-trans/Seireiki-Rayblade#apply) and `README-v0.7.2.txt` for commands. Keep source checksum verification enabled. These are full patches from the original Japanese inputs, not upgrade patches from a previous English build.

### Changes in v0.7.2

* **VGA video support.** Merges the retail video changes from [Rolly (SEGA-SKY)'s VGA patch v1.0](https://segasky.itch.io/seireiki-rayblade-vga-patch-for-sega-dreamcast) into our translated executable and enables the boot VGA flag. The 497 executable byte changes do not overlap the English/font/menu changes. Original region selection and translated disc artwork are retained.
* **Original opening/demo movies.** Restores `MOV055.SFD` and `MOV072.SFD` byte-for-byte from the original Japanese retail disc. Removes every added English movie subtitle, caption, title/UI and ending-title edit. Original video, audio and timing are restored without re-encoding.
* **English gameplay preserved.** No dialogue wording or translation coverage changes. Retains the integrated original Skies Latin font, variable spacing, whole-word dialogue wrapping, library text, battle/UI translations and previous menu/map readability fixes.

### Testing and known limitations

Both restored movie hashes match the original disc. All fourteen game payloads re-extract exactly; all twelve non-movie payloads and the VGA boot area match local 0.7.1. Changed-sector EDC/ECC and the full 1,188,856,032-byte track preservation comparison pass. The release patches are decoded from their exact original inputs and checked against complete target hashes; the real Retro Trans Automatic backend verifies the complete output disc set.

The VGA executable passed **96 native video cases** covering both video routines, all four cable IDs and twelve flag combinations. Separate isolated Flycast cold boots captured **1,200 vblanks each**: VGA reports **640×480 progressive timing**, and composite reaches the TV video path. These are read-only emulator telemetry checks, without visual inspection or gameplay progression; the unchanged executable/boot proof carries forward from local 0.7.1.

**Physical Dreamcast VGA/NTSC/PAL compatibility remains unverified.** Restored-movie playback/skipping/return, newest live map/menu/VRAM behavior, complete routes, long sessions and independent Japanese meaning review still need testing. There are **503 held/untranslated story rows**; unsupported original text can display fallback marks with the Latin-only font. This is not a complete, fully proofread translation.

Fresh-boot the new GDI and load an ordinary in-game memory-card save. Emulator save states may retain old code or artwork. In Flycast, select **VGA** for its emulated cable when testing VGA output; no physical VGA cable is needed on a PC.

### How it was translated

This is a **machine translation**, produced with large language models and then edited. Codex/OpenAI assisted the drafts, tooling and reverse engineering under the project lead's direction. It has not had complete independent human Japanese-to-English proofreading. Names and terminology are tracked in the glossary. This version adds no new translation.
