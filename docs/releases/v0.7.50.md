# Seireiki Rayblade English — v0.7.50

English translation work in progress for the Dreamcast Japanese edition, **T-42201M**.

This release fixes the black screens during New Game and mission dialogue on the tested Dreamcast/GDEMU/VGA setup, combines the existing emulator fixes, and switches distribution to **DCP**. The game files are identical to the 0.7.50 diagnostic reported working on hardware on November 20, 2026.

## Changes since public 0.7.23

- Correct unaligned name-offset reads that caused real-hardware dialogue failures. Keep measured location banners and the original Skies Native 1× font.
- Retain the working renderer, graphics-memory reservation and compact window/marker atlases, addressing the white-panel glitches observed during testing.
- Keep corrected loading placement, fullscreen movies and the movie bottom-edge repair.
- Combine status-panel alignment, signed SP values, Stage 6 lossless text compression, scrolling map-label alignment, movement grids, targeting, split-screen clipping and selection bars. Status and map hooks now occupy separate locations; map filenames are read bytewise.
- Replace per-track xdelta downloads with one DCP per supported input version. VGA boot support and original CD audio are retained.

## Downloads and installation

Use the current [Retro Trans Tools for Windows](https://github.com/retro-trans/retro-trans-tools/releases/latest). Automatic DCP discovery requires **0.5.20 or later**.

| Your input | DCP |
|---|---|
| Original Japanese CUE/BIN | `Rayblade-English-v0.7.50.dcp` |
| Exact public 0.7.23 English output | `Rayblade-English-v0.7.23-to-v0.7.50-upgrade.dcp` |

The corresponding ZIP downloads contain the same DCP plus instructions and notices. Choose one route; do not apply both patches.

For the original game, refresh the app's catalog and use **Automatic**, or use the **DCP** tab with the full patch. For a public 0.7.23 GDI, use the **DCP** tab and the upgrade patch: that older GDI uses offsets which Automatic does not recognize. Select **GDI** output and a new folder. Keep the rebuilt GDI and every generated track together; replace the whole game folder on GDEMU.

The upgrade starts from the last public release, **0.7.23**, not from local diagnostic builds. For other versions, use the full patch with the original Japanese image. Keep source verification enabled. Cold-boot the updated game and load a normal VMU save instead of an old emulator save state.

DCP rebuilds the disc layout. Output track hashes can differ from older raw images; verification checks the complete game-file tree, boot code and CD audio. No xdelta patches or complete game images are included.

## Validation and remaining work

- User-reported passing on the tested **Dreamcast/GDEMU/VGA** setup. This is targeted testing, not a full-game or all-hardware certification.
- Strict SH-4 alignment checks reproduce the previous fault and pass the repaired dialogue caller. Combined checks cover Native glyphs, status panels, map labels, signed numbers, battle graphics, text compression, loading and movie geometry.
- Both release DCP routes are applied to their actual supported source images and compared with the tested target: all 140 game files, boot/VGA data and CD audio are verified. The game payloads are unchanged from diagnostic 0.7.50.
- The translation remains unfinished: 503 held/untranslated story rows, one unidentified room tag and the long Chapter 6 save-label overlap remain. Independent proofreading, full routes, extended sessions and other hardware/video configurations still need testing.
- [Issue #5: Stage 9 CG display](https://github.com/retro-trans/Seireiki-Rayblade/issues/5) remains under investigation; this release does not claim to fix it.
